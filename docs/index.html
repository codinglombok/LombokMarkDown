LombokMarkdown

Zero-dependency Markdown → HTML converter with GFM, metadata extraction, and TOC generation.

Install

npm install lombokmarkdown

Zero dependencies

Pure TypeScript, ~10KB minified, no runtime deps.

Full Markdown

Headings, lists, code, blockquotes, links, images, rules.

Metadata extraction

Pull headings, links, images, and code blocks.

TOC generation

Auto-build a nested table of contents with slugs.

AST access

Inspect the Abstract Syntax Tree directly.

Multi-runtime

Node 18+, Deno, and all modern browsers via ESM.

Quick start

import { Markdown } from 'lombokmarkdown'

const md = new Markdown('# Hello\n\nThis is **bold**.')
const html = md.parse().getHTML()
// => "
Hello
This is bold.
"

const toc = md.getTableOfContents()
const links = md.getLinks()
